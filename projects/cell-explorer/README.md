# Cell Explorer

**Live demo:** https://cell-explorer-three.vercel.app

Interactive light-mode demo that compares **animal** and **plant** cells side by side. Click any organelle (nucleus, mitochondria, chloroplast, and more) to see what it does.

## Features

- Side-by-side animal and plant cell diagrams (SVG)
- Clickable organelles with hover/focus states
- Detail panel: function, where it’s found, and a fun fact
- Chip lists under each cell for keyboard-friendly selection
- Quick comparison of shared vs unique structures
- Clean light theme

## Run locally

```bash
# Option A — any static server
npx serve .

# Option B — open index.html in a browser
open index.html
```

## Deploy

Static site: deploy the repo root to [Vercel](https://vercel.com) (no build step).
